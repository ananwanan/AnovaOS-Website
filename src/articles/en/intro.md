## Start with a boot

AnovaOS is an independent x86_64 operating system written in Rust. The project aims to let developers edit, compile, debug and run programs inside the system, while qualifying existing Linux software one interface at a time.

## What can you try today?

Use the serial shell to observe UEFI boot, run commands and test persistence. The graphical development desktop adds a launcher, PTY terminal, source editor and resource monitor. In M17.5, three fixed C, C++ and Rust projects were entered, compiled, run and reopened after reboot in local QEMU tests.

## Read the evidence

Each validation record describes its machine profile, inputs, observed results and remaining coverage. M16 tracks local storage acceptance separately from remote CI closeout. M18 compiler reconstruction and guest-only image generation each have their own prerequisites.
